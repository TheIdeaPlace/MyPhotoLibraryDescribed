The gallery can now read each photo's description with its position, in the order you choose, on both the Mac and Windows.

## What's new

- **Description is a gallery label.** View > Labels… > Gallery now includes Description, and it's on by default after Position. When you move to a photo that's already described, you hear its description straight away with the other labels: "12 of 400, A dog on a beach at sunset." There's no pause before it, and it isn't read a second time.
  - **Choose the order.** Move Description to the top to hear the description first and the position after: "A dog on a beach at sunset. 12 of 400."
  - **A photo not described yet** is read without its description at first. With Describe Photos Automatically on, the description follows once it's ready.
  - **To stop the gallery reading descriptions,** remove Description from the Shown list. Photos are still described, and the Description panel still shows them.
  - **If you chose your gallery labels in an earlier version,** Description is added after them, so you hear the same as before. You can then move it or remove it.

## What you need

- **Mac:** macOS 27 or later on Apple silicon, with Apple Intelligence turned on.
- **Windows:** Windows 11 version 24H2 or later on a Copilot+ PC.

If the AI isn't available, the app still browses and shows your photos; it just doesn't describe them or answer questions.

## Installing

- **Mac:** download `My-Photo-Library-Described-0.3.1-mac.dmg`, open it and move the app to your Applications folder, replacing the old one. Help > Check for Updates finds newer versions.
- **Windows:** if you have an earlier version, it updates itself, or use Help > Check for Updates. Otherwise open `MyPhotoLibraryDescribed.appinstaller`.

The [user guide](https://github.com/TheIdeaPlace/MyPhotoLibraryDescribed/blob/main/docs/user-guide.md) explains how to use the app. The [privacy policy](https://github.com/TheIdeaPlace/MyPhotoLibraryDescribed/blob/main/docs/PRIVACY.md) lists everything the app sends over the internet, and when.

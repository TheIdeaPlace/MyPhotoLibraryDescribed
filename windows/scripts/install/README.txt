Photo Finder for Windows $VERSION$ ($ARCH$) - test build

To install: run Install.cmd. It installs for you only, with no admin prompt:
  - the app, to %LOCALAPPDATA%\Programs\Photo Finder
  - "Photo Finder" in the Start menu
  - the Windows AI helper for Describe Image and automatic descriptions,
    on a Copilot+ PC with Developer Mode on (this test build's helper isn't signed)
Then it starts Photo Finder. Run Install.cmd again to update.

To uninstall: run Uninstall.cmd. Your photos, and captions and ratings saved
in them, aren't touched.

Use the arm64 build on Snapdragon (Copilot+) PCs and the x64 build on Intel and
AMD PCs.
